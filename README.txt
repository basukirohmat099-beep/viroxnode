AEROVISTA - Fingerprint + Video Background

Project Android berbasis Gradle untuk builder yang menerima ZIP proyek Gradle.
Layar pembuka memakai video lokal assets/aerovista-background.mp4 sebagai background; video muted, autoplay, dan loop.
Animasi sidik jari tahan 2 detik dan musik About You x Multo tetap berasal dari HTML proyek fingerprint.

Build:
- Upload ZIP ini ke ZIPERR dengan mode ZIP dan pilih Debug Build.
- Build belum dijalankan di lingkungan ZIPERR; jika gagal, kirim log terbaru.
